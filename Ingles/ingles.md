# Git & GitHub Vocabulary

## Core Terms & Commands

- **commit** (*confirmar / registrar cambio*): To save a snapshot of your staged changes to your local repository history with a descriptive message.
- **push** (*empujar / subir cambios*): To upload your local commits to a remote repository (like GitHub) so others can see them.
- **pull** (*traer / descargar cambios*): To download changes from a remote repository and automatically merge them into your current local branch.
- **branch** (*rama*): An independent line of development that lets you work on new features or fixes without affecting the main codebase.
- **merge** (*fusionar*): To combine the changes from one branch into another branch.
- **repository** (*repositorio*): A storage folder (local or on GitHub) that holds all your project files and their complete revision history.
- **settings** (*configuración*): The menu or section where you manage options, permissions, and preferences for your repository or account.
- **changes** (*cambios*): Modifications made to files, such as adding, editing, or deleting lines of code.
- **init** (*inicializar*): A command (`git init`) used to turn a regular local folder into a new Git repository.
- **clone** (*clonar*): A command (`git clone`) used to download a full copy of an existing remote repository onto your computer.
- **status** (*estado*): A command (`git status`) that shows which files have been modified, staged, or are untracked in your working directory.
- **add** (*agregar / preparar*): A command (`git add`) that moves modified files to the staging area so they are ready for the next commit.
- **log** (*historial / registro*): A command (`git log`) that displays the chronological list of past commits in a repository.
- **checkout / switch** (*cambiar de rama*): Commands used to move between different branches in your repository.
- **remote** (*remoto*): A version of your repository hosted on the internet or another network (such as on GitHub).
- **fetch** (*obtener*): A command (`git fetch`) that downloads updates from a remote repository without merging them into your local files yet.
- **stage / unstage** (*preparar / quitar de preparación*): To select (`stage`) or deselect (`unstage`) specific file changes to be included in your next commit.
- **stash** (*guardar temporalmente*): A command (`git stash`) that temporarily shelves uncommitted changes so you can work on something else cleanly.
- **diff** (*diferencias*): A command (`git diff`) that shows the exact line-by-line changes between files, commits, or branches.
- **fork** (*bifurcar*): A personal copy of someone else's GitHub repository under your own account, allowing you to freely experiment without affecting the original project.
- **issue** (*incidencia / tarea*): A GitHub feature used to track bugs, tasks, enhancements, or discussions in a repository.
- **main** (*rama principal*): The default primary branch name in a Git repository where the stable code lives.
- **origin** (*origen remoto*): The default alias name Git gives to the remote repository URL you originally cloned from.

## GitHub Buttons & Interface Actions

- **Commit changes** (*Confirmar cambios*): The button in GitHub's web editor used to save your file edits directly to a branch.
- **Create repository** (*Crear repositorio*): The button used to set up a brand-new project space on GitHub.
- **Confirm merge** (*Confirmar fusión*): The final confirmation button that completes the merge of a pull request on GitHub.
- **Code** (*Código*): The main tab in a GitHub repository where you browse files, folders, and find the URL to clone the project.
